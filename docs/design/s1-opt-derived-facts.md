# S1 derived facts: trace audit and experiment design

## Scope and counting

Reviewed all 663 context records in the six local night session traces (97, 63, 151, 130, 121, 101 respectively), including individual payloads from each session. Counts below are payloads containing the named observable shape, not proof that S1 needed or performed a computation. They overlap. Automated counts search literal fact shapes and field presence; wording changes could change them. This is one game and one night's sessions, not a representative population. Payloads are `body.payload`, including trace-added image metadata; no model calls were made. Unknown fields and unscorable directives remain unknown.

Pure overhead cannot be established from payload size alone: choice descriptions and instructions can govern executable semantics, and historical detail can explain failures. Candidates for a separate ablation are repeated full choice descriptions, duplicated directive history/facts/provenance, repeated current reader values in observation and facts, old history metadata and long numeric precision. No content is removed here. Across these 663 serialized payloads, mean characters are choices 9,419, observation 2,872, facts 4,244, instructions 1,191, objective 987, recent history 11,013, directive history 1,841 and provenance 509; overlapping fields and variable presence prevent adding these as independent costs. Mean full payload is 38,076 characters. These are compact JSON character counts, not provider token measurements; image representation and adapter serialization may differ.

## Rule and decision

A derived fact must be a pure measurement from explicitly typed, compatible measured inputs, carry their units and source sequences or measured ages, preserve clock and window boundaries, return null when any necessary input is unknown, and never name or recommend a choice or assert an outcome. Even a true direction of change can steer through selection and emphasis; inclusion and framing need a paired evaluation. Neither a raw difference without known units/previous sequence nor a new count with a selected behavioral window clears this rule on the audited payloads. Existing remaining time and resource counts already answer the clearest arithmetic. Therefore implement no derived facts. Added cost is **0 characters, 0 estimated tokens (characters / 2.5)**; default payload, hash, request and trace paths are untouched. This is not evidence that derived facts cannot help. A future candidate needs typed reader metadata and source-bound previous measurements, plus a declared interpretation for cyclic quantities.

The live directive is separate from bounded history. The 100 open directives are counted from that field; history eviction does not imply expiry. The trace payloads are evidence of what was recorded, not proof of executability or benefit. `build_context` binds choice set to observation sequence; the loop assembles facts then directive provenance, while monitors supply their own summaries. This audit did not reconstruct every source sequence or replay actuator adherence; it does not establish those properties. Image content, prompt hashes, model versions and resets were not verified for this audit.

## Paid bench design — not run

First specify and implement one candidate and freeze a representative, stratified corpus of 100 eligible paired request bodies, with payload and prompt hashes, choice-set version, model and resolved version, schema, game commit, clock/reset and image references. Baseline is current context; treatment adds only the candidate measurement, all other request content identical. Validate source sequences, units and null handling before freezing. Randomize paired call order. Unit: one frozen decision context, clustered by session/game for uncertainty. Five repeats per arm per context measure within-body choice flips and distribution variation. No pilot or retries in this envelope: 2 × 100 × 5 = 1,000 calls. At 38,076/2.5 = 15,230.4 estimated input tokens per call, the baseline estimate is 15.2304 million input tokens, or **$0.640** at $0.042/million; a candidate of C additional characters adds 1,000 × C/2.5 tokens, costing $0.0000168 × C. This excludes output, images and other charges; use actual adapter token counts and pricing to set a higher approved cap before execution. Check balance and obtain explicit approval before any call.

Primary estimand: paired difference in proportion of decisions judged useful for the stated objective and available evidence, averaged over repeats and contexts, not a claim about downstream game success. Before calls, independent blinded human raters label acceptable offered choices using the frozen observation and objective, record rationale and disagreements, and adjudicate without seeing arm or model choice. If evidence does not support a label, score unknown and report it separately. Report paired per-context differences with session-clustered uncertainty, top-choice flip rates, distribution variation, latency, token cost and attempted/successful/billed calls. API failures are unknown for quality, reported separately; do not replace missing outcomes. If labels, sample diversity or noise cannot resolve the effect, report inconclusive. A subsequent matched-reset live experiment is required for actual task outcomes; no offline choice score establishes them.
